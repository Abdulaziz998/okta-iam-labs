# 🔐 Okta IAM Labs

Hands-on Identity and Access Management (IAM) labs using the Okta Admin Console.

This repository demonstrates real-world IAM scenarios including user lifecycle management, access control, authentication security, Single Sign-On (SSO), and identity troubleshooting.

---

# 📂 Labs

## 🔹 Lab 1 — User Lifecycle Management
- Create and manage users  
- Perform password resets  
- Deactivate and reactivate accounts  
- Monitor activity using System Logs  
- Add and manage custom attributes  
- Troubleshoot user sign-in issues  

👉 [View Lab 1](./01-user-lifecycle-management)

---

## 🔹 Lab 2 — Group-Based Access Control (RBAC)
- Create and manage groups  
- Add users to groups  
- Assign groups to applications  
- Implement role-based access control  
- Validate group-based permissions  

👉 [View Lab 2](./02-group-access-management)

## 🔹 Lab 3 — MFA Enforcement with Okta
- Configure MFA authenticators  
- Create MFA enrollment policies  
- Enforce authentication rules  
- Assign policies to groups  
- Validate MFA during login  

👉 [View Lab 3](./lab-03-mfa-enforcement)

## 🔹 Lab 4 — Single Sign-On (SSO) Application Access
- Configure enterprise application access

- Validate inherited user access

- Enforce MFA during SSO sign-in  

👉 [View Lab 4](./lab-04-sso-application-access)
